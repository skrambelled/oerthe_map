# OertheMap

Live-updating map panel for Ancient Anguish (anguish.org), centered on your
position.

## Requires

- MUSHclient
- A prompt that includes `|XCOORD|` and `|YCOORD|`
- The **mush_windows** plugin, installed first

## Install

1. MUSHclient → **File → Plugins... → Add**
2. Select `OertheMap.xml`
3. **Close**

Keep `seed_data.lua` and `coord_config.lua` next to it.

## Controls

- **Zoom**: +/- buttons, or scroll wheel
- **Pan**: click and drag the map
- **SNAP**: re-centers on your position (`map_snap` to toggle)
- **DEPTH**: colors the ocean by depth, once depth data is imported (see
  below)

## Map data

`seed_data.lua` is generated by `map_import_seed <path>`, run against a
saved copy of either anguish.org's map page or a
[skrambelled/aa-map](https://skrambelled.github.io/aa-map/html/map.html)
export.
